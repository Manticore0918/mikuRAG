# Miku City Release Guide

## Rollout window

The Melody Harbor release window is Tuesday from 09:00 to 11:00 Singapore time.
The release manager must approve the rollout before the first production change.

## User communication

Send the customer update after the health checks pass, but no later than thirty minutes
after the rollout finishes. If a health check fails, pause the rollout,
tell support that the release is delayed, and keep the previous version active.

## Follow-up ownership

The release manager owns the rollout decision. The support lead owns the customer
update and links it to the incident record when a rollback occurs.
