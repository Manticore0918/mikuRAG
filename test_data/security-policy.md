# Information Security Policy

## Passwords

Passwords must contain at least 14 characters.

Employees must not reuse company passwords on external websites.

## Multi-Factor Authentication

Multi-factor authentication is required for email, source control, cloud
infrastructure, and administrative systems.

## Security Incidents

Suspected security incidents must be reported to security@example.test within
one hour of discovery.

Employees should not attempt to investigate suspected attackers themselves.
