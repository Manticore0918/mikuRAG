# Atlas Search Release Notes

## Version 1.4 — March 10, 2026

- Added Microsoft Word document support.
- Increased the maximum file size from 20 MB to 25 MB.
- Reduced normal indexing time from ten minutes to five minutes.

## Version 1.3 — January 15, 2026

- Added HTML document support.
- Added document deletion.
- Introduced 90-day audit metadata retention.
