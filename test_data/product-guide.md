# Atlas Search Product Guide

Atlas Search is an internal document-search application.

## Supported File Types

Atlas Search supports PDF, Markdown, plain text, Microsoft Word, and HTML files.

Image-only PDF files require OCR before their contents can be indexed.

## File Size Limits

The maximum file size is 25 MB per document.

## Indexing

New documents normally become searchable within five minutes.

Deleting a document removes it from search results, but audit metadata is
retained for 90 days.
